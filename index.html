    Dropbox, backups & printing
    1. In Dropbox, find the latest shared cookbook. On iPhone or iPad, make it available in Files by enabling Dropbox under Browse → More → Edit, or use Dropbox’s export menu to save a copy to Files.
    2. Select Import from Files and choose the cookbook JSON. Open a recipe, edit it, then select Save Recipe.
    3. Select Save & Export. Locate the downloaded JSON in your browser’s downloads or the Files app. Move or upload it to the shared Dropbox folder. Wait for Dropbox to finish uploading.
    4. Keep the previous shared file in Backups before promoting the new file. Ask everyone to import the new shared copy before editing. Browser storage stays on this device and never syncs with Dropbox.
    5. To recover, export your current working copy first, then import a dated backup. Preview a recipe’s Revision History to recover only its typed values.
